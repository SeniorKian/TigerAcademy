# گزارش تأییدها و مدیریت منو — ۱۲ شهریور ۱۴۰۵

## تغییرات

- نصب SweetAlert2 و ساخت توابع مشترک تأیید، پیام موفقیت، خطا و دریافت URL با ظاهر فارسی و راست‌چین.
- جایگزینی تأییدهای بومی مرورگر در منو، طرح‌ها، مشاوره‌ها، محتوا، سؤالات متداول، حساب/نقش کاربران و وضعیت سفارش؛ جایگزینی prompt لینک/تصویر HTML Editor.
- تمرکز اولیه تأییدهای حساس روی انصراف، جلوگیری از بستن پنجره هنگام درخواست و نمایش خطای API بدون بسته‌شدن پنجره.
- بازنویسی صفحه منو: جست‌وجو، فیلتر وضعیت، بازخوانی، جلوگیری از ثبت تکراری، اعتبارسنجی، پیام خطای قابل فهم و فعال‌سازی مجدد.
- اعتبارسنجی سمت سرور برای عنوان، طول لینک، ترتیب، نوع URL و والد. ممنوعیت والدِ خود، والد ناموجود یا زیرمنو، و تغییر والدِ منویی که فرزند دارد. فعال‌سازی زیرمنو نیازمند والد فعال است.
- اصلاح انتخاب مقصد لینک‌های قدیمی /plans، /faq و /contact در فرم ویرایش؛ حفظ مقصد سفارشی خارج از گزینه‌های آماده.
- دسترس‌پذیری Modal مشترک: نام قابل خواندن، Escape، حفظ تمرکز داخل پنجره و بازگرداندن فوکوس.

| تأیید طرح، مشاوره، محتوا، سؤال، حساب، نقش و سفارش | پنجره جدید باز شد؛ همه عملیات این بخش‌ها لغو شدند و داده اصلی تغییر نکرد |
| HTML Editor | انتخاب متن در پنجره URL حفظ شد و خروجی `<a href="/#faq">پیوند آزمایشی</a>` ساخته شد؛ URL ناقص و آدرس تلفن برای تصویر رد شدند |

## وضعیت داده‌های آزمایشی

دو رکورد با شناسه‌های ۱۶ و ۱۷ و برچسب `[QA]` و تاریخ `۱۴۰۵۰۶۱۲` ساخته شدند. هر دو در پایان غیرفعال‌اند و در منوی عمومی نمایش داده نمی‌شوند. حذف دائمی انجام نشد؛ از پنل قابل بازیابی‌اند. پیش‌نویس HTML بدون ذخیره بسته شد. هیچ سفارش، حساب، نقش یا محتوای اصلی تغییر نکرد.

## بررسی فنی و محدودیت‌ها

- `npm test`: ۳۰ تست مستقل برای لینک‌ها.
- بیلد TypeScript/Vite و بیلد API موفق؛ lint فایل‌های تغییرکرده موفق.
- هیچ استفاده‌ای از `window.confirm`، `window.prompt` یا `window.alert` در کد کلاینت باقی نماند.
- lint کلی پروژه همچنان خطای قبلی `react-hooks/set-state-in-effect` در `PaymentsPage.tsx:38` دارد؛ این فایل در این تغییرات ویرایش نشد.
- Vite همچنان درباره بزرگ‌بودن بسته اصلی JavaScript هشدار می‌دهد.
- آزمون مالی یا تغییر واقعی نقش انجام نشد؛ تنها مسیر تأیید و انصراف آن‌ها بررسی شد. این گزارش ممیزی جامع امنیتی یا تست همه امکانات سامانه نیست.
